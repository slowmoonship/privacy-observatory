# V0.1 建议范围与下一阶段

## 建议指标

核心：XMR/ZEC 当前及历史市值、供应量、ZEC 屏蔽供应量与占比、四屏蔽池余额历史。XMR 日交易量可用；ZEC 总交易及涉及屏蔽池交易技术上可用，但因 ZecBlock 未声明数据许可，先不发布其历史序列，待取得授权或验证有许可的替代数据源。协议列表与整体 TVL 排行适合作为辅助，先核实 DefiLlama 上游权利；展示协议链标签、时间、计入状态和来源，不制作分链 TVL 汇总。

PriFi 的数据仅限非商业使用；若未来需要商业用途，先替换或取得授权。池历史仅从 2026-07-30 起，避免暗示全历史；不将缺失值填零。发布时显示来源、许可、数据时间和不构成投资建议，区分 ZEC 全部交易与屏蔽相关交易。

## 下一阶段网页开发计划

1. 明确上游数据使用授权；针对不确定的 ZEC 交易和协议 TVL 取得许可或验证替代来源，未解决时保留缺项说明。
2. 建立 Python 采集转换：每日按来源一次抓取，检查状态、字段、日期、空值和过期；将单位统一并生成带来源、许可证、采集和观测时间的静态 JSON。失败时退出并保留现有发布版本，不把旧数据标为新数据。
3. 使用 React + TypeScript + Vite + ECharts 构建中文静态页面：两币对比卡片及历史图、ZEC 四池图、辅助协议列表；图表显示 UTC、来源与口径，空值断线。
4. 用 GitHub Actions 每日更新 JSON、构建并部署 GitHub Pages；配置最小必要权限、缓存和失败提示。测试转换与边界、许可显示、移动端、图表单位和部署路径。

本阶段不实现上述功能；不引入数据库、Docker、常驻后端或 AI 定时任务。开放数据集、独立计算方法和下载功能留待 V0.2。
