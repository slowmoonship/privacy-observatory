## 更新与质量门禁

GitHub Actions 每天 UTC 04:37（北京时间 12:37）配置刷新，也支持手动触发。自动更新完整 Coin Metrics 历史，重算表格并对比已提交快照，保留历史修订范围。旧日期缺失退化、未到最近完整日、格式、许可、白名单或哈希校验失败时停止新部署。通过后才以普通前进提交持久化整套验证快照，无变化时复用旧提交。每次从同一组验证后的规范表生成下载、网页投影、统计口径及动态质量核验。协议目录按上次已核验版本复用，日期不随日更变动。

2026-11-24 的历史专项审计覆盖截至 2026-11-23 的固定样本。它验证了 PriFi 千美元舍入，并以独立区块抽样和时间归桶重算证明两个 ZEC 案例；3,530 个其余差异日仍未归因。五条 ZecStats 记录内部加总不闭合，候选高度匹配不能证明源实际观测高度。日更不会重跑历史专项。样本范围内出现修订时，报告会列出受影响起止日并保留原证据版本。

数据来自第三方。SlowMoonShip 完成格式标准化和质量核验；独立区块工作仅限上述抽样。Coin Metrics 与历史对照所用 PriFi 适用 CC BY-NC 4.0，须署名并限非商业使用。[Coin Metrics](https://github.com/coinmetrics/data#license) · [PriFi](https://prifi.info/data/) · [ZecStats](https://zecstats.org/api)

## 公开发布边界

已批准的规范文件及公开摘要通过构建白名单。原始响应、受限对账或池余额文件均不进入现行版本。旧 V0.1 的公开 Git 提交曾包含池快照；撤下当前部署路径无法撤回旧历史。公开版本保留原有历史，如需对旧历史进一步处置，须另行确认。
