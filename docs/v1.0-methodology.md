# V1.0 网页指标口径

## 市场与网络

本站以非商业研究方式使用 Coin Metrics Community Data，许可为 CC BY-NC 4.0。数据按资产和 UTC 日筛选，派生指标使用十进制运算，界面做显示舍入。抓取时间与统计日期分别记录。市值、每日交易数与 SplyCur 沿用现有研究数据集和完整下载。新增指标只随网页展示，V1.1 计划提供正式数据集及下载。 [数据许可](https://github.com/coinmetrics/data#license) · [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/)

| 网页字段 | 计算或来源 |
| --- | --- |
| 7/30 日交易均线 | 连续 7 或 30 个完整 UTC 日的 TxCnt，含当日，分母分别固定为 7 或 30。窗口中有任何缺日或缺值则为空，真实零值计入。TxCnt 排除 coinbase，统计的是网络交易 |
| 每日区块数 | BlkCnt，按资产 UTC 日计入主链的区块。ZEC 在 2026-11-06 激活 NU7，将目标间隔由 75 秒改为 25 秒 |
| 每日手续费总额 | FeeTotNtv，按源统计的链上手续费，包含按协议移出流通的部分，单位为该资产 |
| 平均每笔网络交易手续费 | FeeTotNtv ÷ TxCnt，用同一来源和资产的日交易笔数推算，包含零费交易。TxCnt 非正或输入缺失时为空 |
| 每日手续费美元估值 | FeeTotNtv × PriceUSD，使用该日期 UTC 收盘参考价。估值对应整日费用，实际每笔成交时的 USD 成本会受当时价格影响 |
| 平均每笔交易费用美元估值 | FeeTotNtv × PriceUSD ÷ TxCnt。分母非正、价格非正或输入缺失时为空 |
| 每日发行量 | IssTotNtv，按来源定义的当日总发行量。ZEC 包含协议分配，矿工实得收入是更窄的范围 |
| 供应量趋势 | SplyCur，与 `privacy_network_daily` 同一快照。ZEC 的此字段与节点同块核算的全链发行供应分列 |
| 365 日供应增长 | 100 × [SplyCur(t) ÷ SplyCur(t−365 个 UTC 自然日) − 1]。缺少对应日、任一值缺失或分母非正即为空 |
| 算力趋势 | HashRate，XMR 以 H/s、ZEC 以 GSol/s，分链展示。2026-11-06 ZEC 两种日估计有过渡差异，NU7 前后的趋势应结合共识切换理解 |

展示快照保存最近 1,095 个完整 UTC 日，计算时另取得 365 个前置日。原生币的费用、供应和发行按币种切换。费用均值会被少数高费用交易拉高，页面的美元值采用逐日参考价估算。 [交易定义](https://docs.coinmetrics.io/network-data/network-data-overview/transactions/transactions) · [手续费定义](https://github.com/coinmetrics/product-docs/blob/master/docs/network-data/network-data-overview/fees-and-revenue/fees.md) · [PriceUSD](https://github.com/coinmetrics/docs-website/blob/master/asset-metrics/market/priceusd.md) · [发行定义](https://github.com/coinmetrics/product-docs/blob/master/docs/network-data/network-data-overview/supply/supply-issuance.md) · [NU7](https://zips.z.cash/zip-0259)

## Zcash 价值池

数据契约保留一个区块的高度、哈希、UTC 块时间、采集时间、来源与许可。供应和六池余额以十进制字符串传输原始整数 zatoshi，采用整数检查。全链已发行供应为六池之和。屏蔽池账面余额为 Sprout + Sapling + Orchard + Ironwood。屏蔽占比使用同块全链发行供应作分母，四池构成使用同块屏蔽账面余额作分母。Lockbox 与 Transparent 单列，NSM 位于发行供应核算之外。NU7 后 Sprout 余额不可支出。区块年龄超过 48 小时显示过期提示并保留通过校验的值及来源时间。

候选构建仅返回公开状态说明，现阶段生产来源仍待确认。原研究数据集中暂停的历史池表继续提供字段范围、统计口径、质量报告和 Manifest，历史数据发布另行核验。 [Zebra 价值池 RFC](https://zebra.zfnd.org/next/dev/rfcs/0012-value-pools.html) · [ZIP 259](https://zips.z.cash/zip-0259)

## 协议目录

`privacy_protocol_registry` 保留原主键 `(protocol_id, chain_id)`，扩充主网部署及资产类型和 UTC 核验日期。部署地址和角色是代表性示例，出处逐行列出。Base ScopeLift Umbra 为 EVM 隐匿收款合约，Solana Umbra Privacy / Nimbus 为独立项目。网页与 CSV/Parquet 从同一注册表生成。协议市场量化数据仍属研究候选。
