# V1.0.0 隐私资产观察站

V1.0 扩展 Monero 与 Zcash 的网络活动、经济学与技术对照，采用 Coin Metrics Community Data 和协议官方材料，继续提供完整的 V0.2 研究数据集下载。 [指标口径](v1.0-methodology.md)

## 网络与经济学指标

- 网络活动增加 7 日、30 日平均交易数及每日区块数。
- 网络经济增加原生币手续费总额、按网络交易数推算的平均手续费、按当日 UTC 收盘参考价估算的手续费总额及平均手续费、每日发行量和 365 日供应增长率。
- 算力按链查看，ZEC 标注 NU7 切换日的估计差异。技术对照注明主网状态、隐私模式、匿名集、选择性披露和货币政策。
- 发布快照中，十个新增字段覆盖 2023-11-26 至 2026-11-24 UTC，XMR 与 ZEC 各 1,095 个有效日。旧市值、交易和供应历史及下载保持完整。

新增经济指标随网页提供展示快照，完整研究数据集留待 V1.1。Coin Metrics 数据用于非商业研究，适用 CC BY-NC 4.0。ZEC 的总发行量涵盖协议分配。不同 PoW 算法按各链内自身趋势解读。 [Coin Metrics 数据许可](https://github.com/coinmetrics/data#license) · [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/)

## ZEC 屏蔽供应展示

Zebra 的同块整数校验、六池闭合与两个独立服务对账已完成。本站生产采集和持续公开发布授权仍待落实，自己的价值池快照和历史表保持暂未开放。页面提供可由访客主动加载的 **ZecZcash 授权挂件**，展示第三方日度屏蔽份额及总额、观测日期和延迟提示。挂件与本站数据集分列，金额和比例由第三方直接显示。 [ZecZcash 挂件与使用许可](https://zeczcash.com/tools/shielded-supply-widget)

## 数据集与更新

市场、网络研究数据集仍提供完整历史 CSV/Parquet、Schema、Manifest、方法和质量报告。协议注册表有 13 条人工核验的主网部署，保留机制、资产、日期和官方出处，覆盖六条目标链及已有 Polygon。TVL 和资金流数据继续待核。

GitHub Actions 每日 UTC 04:37 配置触发，支持手动运行。完整历史与有界经济快照从同一截止日校验，动态生成下载、图表、质量报告和 Manifest。失败时保留已有生产快照，无数据变化时复用原提交。V1.1 的最高优先级候选为自主 Zcash 数据源建设评估。
